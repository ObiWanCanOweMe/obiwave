# Upstream SUB/WAVE v1.11.0 Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrate exact upstream SUB/WAVE `v1.11.0` into ObiWave, including all native support code, preserve the fork's reviewed contracts, and merge the reviewed result into `develop` without publishing or deploying anything.

**Architecture:** Create one exact two-parent merge from fork `develop` into upstream tag `v1.11.0`, resolve every conflict semantically, audit every shared changed path, and verify each ownership group independently before the final repository gate. Native iOS/Android source remains part of the composed tree and test surface, but EAS, store builds, device installation, release creation, image publication, production access, and vulnerability scanning are prohibited.

**Tech Stack:** Git, Node.js 22.23.2, TypeScript, React/Next.js, Expo/React Native, Swift source/config contracts, Express, Liquidsoap, Docker Compose/Buildx, Node test runner, Playwright verifier scripts, GitHub CLI.

**Spec:** `docs/superpowers/specs/2026-08-26-upstream-v1.11.0-integration-design.md`
