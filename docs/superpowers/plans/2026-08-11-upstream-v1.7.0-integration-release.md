> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Merge exact upstream SUB/WAVE `v1.7.0` into ObiWave, preserve fork-only behavior, merge a reviewed green integration pull request, publish immutable fork release `v1.7.0-obiwave.1`, and deploy it successfully to Ark.

**Architecture:** Work from a linked worktree rooted at the exact fork head and create one non-fast-forward merge whose second parent is the exact upstream tag. Resolve the 25 predicted conflicts by composing upstream's Zod/form/query architecture with ObiWave's provider, authentication, playback, analyzer, release, and deployment contracts; verify locally and on GitHub; then use the repository's tag-triggered image, security, and Portainer pipeline.

**Tech Stack:** Git, Node.js 22, npm lockfiles, TypeScript, Zod 4, React Hook Form, TanStack Query, Next.js, Python 3, Docker Buildx, GitHub Actions, GHCR, Trivy, and Portainer.

- Execute in `.worktrees/integrate-upstream-v1.7.0` on branch `integrate/upstream-v1.7.0`.
