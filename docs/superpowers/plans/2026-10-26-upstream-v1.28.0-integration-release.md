## Constraints and review focus

- Preserve provider-owned credentials, custom headers, Google per-leg settings, embedding authorization, serialized swaps and failover cache ownership.
- Preserve four-codec listener buffer/auth behavior and native station-password safety. Lyrics timing must use the listener edge and clear stale responses across track/station changes; device delay offsets intentionally persist across stations.
- Preserve durable jingle reload, shared IPC writers, stable voice IDs and mixer restart recovery. New jingle overlays must not stack spoken content or consume a stale opening.
- Preserve detailed fork documentation, generated schemas/theme tokens and CLI compose assets. Native code is validated; native store publication is outside this server-release request.
- Eleven immutable published images, immutable upstream CUDA analyzer mirror, and same-run CUDA TTS digest are mandatory. PR targets develop; fork release workflow owns tags and production deployment.
