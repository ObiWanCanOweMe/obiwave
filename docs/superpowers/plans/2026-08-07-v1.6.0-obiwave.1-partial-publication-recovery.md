# v1.6.0-obiwave.1 Partial Publication Recovery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the interrupted `v1.6.0-obiwave.1` publication without changing its five existing images, then scan all ten digest-qualified images and deploy the existing release.

**Architecture:** A checked-in partial-recovery manifest statically approves the release source, scanner, five preserved digests, and five permitted builds. A manual workflow validates that state, builds only absent images from the release commit, seals Buildx outputs plus registry observations into a full runtime manifest, passes that manifest through the reusable digest-qualified scanner, and deploys only after aggregate policy succeeds.

**Tech Stack:** Node.js 22 ESM and `node:test`, GitHub Actions reusable workflows, Docker Buildx/QEMU, GHCR, Trivy 0.67.2, Portainer, GitHub CLI.
